## Comando

Script descartável no scratchpad (`a11y-audit.ts`), Playwright com `args: ['--mute-audio']`, contra servidor próprio com `SOUND_MUTED=true`:

```
SOUND_MUTED=true bunx --bun vite --port 5198 --strictPort   # mudo, porta própria
bun <scratchpad>/a11y-audit.ts                              # BASE_URL=http://localhost:5198
```

Fluxo: `/` (MainMenu) → SETTINGS → BACK → PLAY (HeroSelect) → BACK → `/?skipMenu=1&hero=jack&round=3&seed=1&god=1` → `__GAME__.scene.getScene('Game').finishRound()` (Shop).
